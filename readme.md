Judul: AICHALIVERET SCM (SaaS Supply Chain Management khusus Garment/Konveksi).

Problem: Industri konveksi masih sering pakai Microsoft Excel yang ribet dan rentan salah hitung.

Solution: Aplikasi web interaktif untuk input per ball (1201-1599 yard), kalkulasi otomatis roll-to-kodi sesuai ukuran spesifik, manajemen transport supir (SIM/KTP/GPS), serta pemisahan laman untuk Direktur, Manufacture, dan CMT.

Tech Stack: Python, Streamlit, GitHub.
